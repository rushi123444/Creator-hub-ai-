# Components

Import everything from the barrel: `import { Button, Card, DataTable, useToast } from '../components';`
Styles live in `src/styles/components.css`; colours and radii come from `tokens.css` variables. Layouts (`AppLayout`, `AdminLayout`, `AuthLayout`, `PublicLayout`, `PublicNav`, `PublicFooter`) are in `src/layouts` (PublicNav takes `links=[{href,label,key?}]`, PublicFooter `links=[{to,label}]`).

| Component | Props |
|---|---|
| `AIOutputCard` | AIOutputCard: one piece of generated text with Copy / Regenerate / Save / Edit (edit in place). Props: - title, text (string shown and copied), isSample (shows the "Sample" badge), meta (node under the title, e.g. hook type Tag) - onRegenerate() (shows button; pass `regenerating` while it runs), regenerating - onSave(text) (shows button; pass `saving`, `saved` to switch the label), saving, saved - editable (default true): Edit opens a textarea; "Save changes" calls onChange(newText) so the parent updates its state - onChange(text), rows (edit textarea rows), children (extra content under the text), className |
| `Avatar` | Avatar: image with initials fallback. Props: name, src, size (px, 32), className. |
| `Badge` | Badge: small status label. Props: tone ('neutral'\|'accent'\|'success'\|'warning'\|'danger'\|'info'), icon (lucide component), dot (leading colour dot), className. |
| `Button` | Button. Props: variant ('primary'\|'secondary'\|'ghost'\|'danger'), size ('sm'\|'md'\|'lg'), loading, icon (lucide component, leading), iconRight, block (full width), to (renders a router Link), href (renders <a>), type (default 'button'), plus any native button props. |
| `Card` | Card: bordered surface. Props: as (tag, 'div'), padded (default true), interactive (hover state), flat (no border emphasis), className, plus native props. |
| `ChartCard` | ChartCard: SectionCard wrapper for a chart with loading / error / empty states. Props: title, description, action (header node, e.g. SegmentedControl), loading, error (safe string), onRetry, empty (boolean, shows EmptyState), emptyText, height (chart area min-height, default 260), footer, className. Children: the chart, e.g. <AreaTrend .../>. |
| `Checkbox` | Checkbox. Props: label (node), description, checked, onChange(event), disabled, className, plus native input props. |
| `ConfirmDialog` | ConfirmDialog. Props: open, onClose, onConfirm, title, description, confirmLabel (default "Confirm"), cancelLabel, danger (red confirm button), loading (disables buttons, shows spinner on confirm). |
| `CopyButton` | CopyButton: copies `text`, flips to a check for 1.8s and shows a toast. Props: text (string \| () => string), label (button text; omit with iconOnly), iconOnly, size, variant, className. |
| `DataTable` | DataTable: table on desktop, stacked cards on mobile (<=640px). Props: - columns: [{ key, header, render?(row) -> node, sortable?, sortValue?(row), align?: 'right', primary?: true (card title on mobile), hideOnMobile?, width? }] - rows: array, rowKey: field name or (row)=>key (default 'id') - loading (skeleton), emptyTitle / emptyDescription / emptyIcon / emptyAction (empty state), onRowClick(row) - defaultSort: { key, dir: 'asc'\|'desc' } (client-side sort; omit `sortable` columns to keep server order) - caption (screen-reader table caption), className |
| `Drawer` | Drawer: side panel overlay with the same focus handling as Modal. Props: open, onClose, title, side ('left'\|'right', default 'right'), width (css, default 420px), footer, className, hideHeader (for custom content, pass ariaLabel), ariaLabel. |
| `Dropdown` | Dropdown / menu with keyboard support (Arrow keys, Home/End, Escape, Enter). Props: - trigger: a single element (e.g. <Button/>); it receives onClick + aria props. - items: [{ label, icon?, onSelect?, danger?, disabled?, active? }, { type: 'separator' }, { type: 'label', label }] - align: 'start' \| 'end' (default 'end'), width (css), className - children: custom panel content instead of `items` (use render form (close) => node to close it yourself) - open / onOpenChange: optional controlled mode. |
| `EmptyState` | EmptyState. Props: icon (lucide component, default Inbox), title, description, action (node, e.g. <Button/>), compact (less padding, for use inside cards), className. Defaults come from the shared "state.*" strings. |
| `ErrorBoundary` | ErrorBoundary: friendly fallback, never shows technical text. Props: children, compact (inline card instead of full page). Resets itself when `resetKey` changes (the router passes the pathname). |
| `ErrorState` | ErrorState: friendly error with Retry. Pass the SAFE string from useAsync().error / getFriendlyError(err). Props: message (shown as the description), title, onRetry (shows the Retry button), compact, className. |
| `FormField` | FormField: label + control + hint + error. Input, Textarea, Select, PasswordInput and SearchInput placed inside pick up the id, aria-describedby and invalid state automatically. Props: label, hint, error (string), required, optionalLabel (text shown for optional fields), className. For custom controls, use the render form: children as (fieldProps) => node, fieldProps = { id, 'aria-describedby', 'aria-invalid' }. |
| `IconButton` | Icon-only button. `label` is REQUIRED (aria-label + native tooltip). Props: icon (lucide component), label, size ('sm'\|'md'\|'lg'), variant ('ghost'\|'secondary'\|'danger'), active, plus native button props. |
| `Input` | Input. Props: icon (lucide, leading), suffix (node at end), invalid, size ('md'\|'sm'), className (wrapper), inputClassName, plus native input props. Inside FormField it is labelled automatically. |
| `LanguageSelect` | LanguageSelect. Two modes: - variant 'menu' (default): globe button + dropdown that changes the INTERFACE language (useI18n().setLang). - variant 'field': native <select> bound to `value`/`onChange(code)`, for choosing the language of AI output or content. Props: variant, value, onChange, size, className, id. |
| `Logo` | Original spark/hub mark: a four-point spark with three satellite nodes. |
| `Modal` | Modal dialog (glass backdrop, focus trap, Escape, scroll lock, focus restore). Props: open, onClose, title, description, size ('sm'\|'md'\|'lg'\|'xl'), footer (node, e.g. buttons), dismissable (default true: backdrop click + close button), className, children, initialFocus (css selector), hideHeader (render your own content; pass `ariaLabel`), ariaLabel. |
| `PageHeader` | PageHeader: h1 + description + right-aligned actions. Props: title, description, eyebrow, actions (node), badge (node next to title), className. |
| `Pagination` | Pagination. 1-based `page`. Props: page, pageSize, total, onChange(page), className. Renders nothing when everything fits on one page. Shows "Showing a–b of n" and page buttons (compact on mobile). |
| `PasswordInput` | PasswordInput: Input with a show/hide toggle. Props: same as Input (value, onChange, autoComplete, ...). |
| `PlatformIcon` | PlatformIcon. Props: platform (slug), size (16), withLabel (show the name next to the icon), className. Decorative unless withLabel is false and `title` is wanted: the slug label is exposed via title. |
| `RouteGuards` | Requires a signed-in user; otherwise sends them to /login and back after. Renders <Outlet/> or children. |
| `SampleBadge` | SampleBadge: subtle "Sample" label for sample data or sample AI output. Props: label (override text), className. |
| `ScrollToTop` | ScrollToTop: mount once inside the router. Scrolls to top on path change (not on query/hash changes). |
| `SearchInput` | SearchInput: controlled search box with clear button. Props: value, onChange(value: string), placeholder, label (aria-label, default "Search"), size, className. Pair with useDebounce for API calls. |
| `SectionCard` | SectionCard: Card with a header row (title, optional description, optional action) and a body. Props: title, description, action (node shown top-right), footer (node), padded (body padding, default true), as, className, bodyClassName, id. |
| `SegmentedControl` | SegmentedControl: compact single-choice toggle (radiogroup, arrow keys). Props: options ([{ value, label, icon? }]), value, onChange(value), ariaLabel, size ('md'\|'sm'), block, className. |
| `Select` | Native select (best accessibility on mobile). Props: options ([{ value, label }] or string[]), placeholder (adds a disabled-looking empty first option), invalid, size ('md'\|'sm'), value, onChange, plus native select props. Children <option> also work. |
| `Skeleton` | Skeleton block. Props: width, height, radius, className, style. |
| `Spinner` | Spinner. Props: size (px, 16), label (screen-reader text, default 'Loading'), className. |
| `StatCard` | StatCard: KPI tile. Props: label, value (already formatted), icon (lucide), delta (number, % change; shows up/down colour), deltaLabel (e.g. "vs last 30 days"), hint (small text under the value), loading (skeleton), className. |
| `StatusPill` | StatusPill for content status (idea\|draft\|script\|recording\|editing\|scheduled\|published). Props: status, className. |
| `Switch` | Switch (role=switch). Props: checked, onChange(checked: boolean), label, description, disabled, className. |
| `Tabs` | Tabs (WAI-ARIA tablist with arrow-key navigation). Controlled. Props: tabs ([{ value, label, count?, icon?, disabled? }]), value, onChange(value), ariaLabel, className. Render panels yourself: <div role="tabpanel" id={panelId(value)} aria-labelledby={tabId(value)}> using the exported helpers or just conditionally render content below <Tabs/> (panel wiring optional). |
| `Tag` | Tag: small pill. Props: onRemove (shows a remove button), removeLabel, tone ('neutral'\|'accent'), onClick (makes it a button), className. |
| `Textarea` | Textarea. Props: rows (4), invalid, mono (monospace), plus native textarea props. |
| `Toast` | ToastProvider (mounted once in main.jsx) and useToast(). const toast = useToast(); toast.success('Saved'); toast.error('Could not save'); toast.info('...'); toast.fromError(err) -> error toast with getFriendlyError(err) Each accepts (message, { duration }) ; default 4s, errors 6s. Max 4 visible. |
| `Tooltip` | Tooltip shown on hover and keyboard focus. Props: content (string), children (a single focusable element), side ('top'\|'bottom'). For icon-only buttons prefer IconButton (it has an aria-label); use Tooltip to add extra explanation. |
| `charts` | Recharts theme helpers (colours come from CSS tokens so light/dark both work). * CHART_COLORS array of 6 CSS colours (var(--chart-n)) chartColor(i) colour for series i <AreaTrend\|LineTrend\|BarCompare data xKey series height format xFormat stacked /> series: [{ key, name?, color? }]; data: array of objects; format(value) -> label for ticks + tooltip <DonutChart data nameKey valueKey height format /> <ChartTooltip /> and AXIS / GRID props for custom Recharts compositions: <Tooltip content={<ChartTooltip format={fmt} />} cursor={CURSOR} /> |

Charts helpers (`charts.jsx`): `CHART_COLORS`, `chartColor(i)`, `AreaTrend`, `LineTrend`, `BarCompare`, `DonutChart`, `ChartLegend`, `ChartTooltip`, `AXIS`, `GRID`, `CURSOR`. Series: `[{ key, name?, color? }]`; `format(value)` formats ticks and tooltips.
Skeleton exports: `Skeleton, SkeletonText, SkeletonCard, SkeletonStat, SkeletonRows, SkeletonChart, PageSkeleton`. Tag exports: `Tag, TagList`. Toast: `ToastProvider, useToast`. Logo: `Logo, LogoMark`.
Route guards (`RouteGuards.jsx`): `ProtectedRoute` (signed-in only), `RoleRoute roles={[...]}` (wrong role goes to that role's home), `GuestRoute` (login/register pages).
